{% comment %} Клиентская интеграция PostHog (posthog-js). Подключается из base.html. Если ключ не задан (posthog_enabled=False) — блок не рендерится вовсе, никакие внешние скрипты не грузятся (graceful no-op). Что делает на клиенте: * грузит posthog-js и инициализирует проект; * register({platform:'web'}) — добавляет platform ко ВСЕМ клиентским событиям (аналог android/ios из мобильного чеклиста); * автозахват $pageview — питает Insights → Paths (screen flow); * identify(distinct_id, {email,name,plan}) для залогиненного пользователя — Persons показывают email/имя/план, события не «осиротеют». {% endcomment %} {% if posthog_enabled %} {% endif %}
