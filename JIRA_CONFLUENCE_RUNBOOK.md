# Jira / Confluence шаблон для runbook COHUB

## Заголовок задачи Jira

Создать и оформить runbook для сайта COHUB для поддержки, деплоя и восстановления сервиса

## Описание задачи

Необходимо подготовить полный operational runbook для сайта COHUB, который позволит команде поддержки и разработчиков быстро:
- запускать приложение локально и на сервере;
- выполнять обновления;
- проверять работоспособность;
- создавать и восстанавливать backup;
- диагностировать и устранять типовые проблемы;
- действовать по сценариям инцидентов.

## Цель

Обеспечить понятную и структурированную документацию для эксплуатации сайта COHUB и снизить время реакции на инциденты.

## Текст для Confluence

Сайт COHUB — это Django-приложение для управления совместной жизнью, комнатами, задачами, расходами и долгами. Данный runbook описывает порядок запуска проекта, проверки его работоспособности, обновления, резервного копирования, восстановления данных и действий в случае инцидентов.

### Основные компоненты
- Backend: Django 5.2.8
- API: Django REST Framework
- База данных: SQLite локально / PostgreSQL в production
- Frontend: HTML, CSS, JavaScript

### Основные шаги
1. Установить зависимости: pip install -r requirements.txt
2. Применить миграции: python manage.py migrate
3. Запустить приложение: python manage.py runserver
4. Проверить доступность: /, /dashboard/, /admin/, /api/
5. Создать backup: python manage.py backup_data --compress
6. При необходимости выполнить restore из backup
7. При проблемах: проверить логи, проверить переменные окружения, выполнить collectstatic, перезапустить процесс

### Инцидентные сценарии
- Сайт недоступен — проверить процесс, порт, логи, БД
- Ошибка базы данных — проверить миграции и восстановить backup
- Ошибка после обновления — выполнить rollback и проверить работоспособность

### Рекомендуемый чек-лист перед релизом
- зависимости установлены
- миграции применены
- collectstatic выполнен
- основные URL доступны
- admin работает
- backup создан
- логирование доступно
